# Guide: create a free GitHub account

Only the person can do this, in their own web browser. Give ONE step at a time and wait for them to say "done" (or tell you what they see) before the next. Offer help if they are stuck. Reassure them: it is free, and nobody needs to pay for anything.

Steps:
1. "Open this link in your web browser: https://github.com/signup . Tell me when the page is open."
2. "Type your email address. Use one you can open right now." Wait.
3. "Choose a password. Make it long, and save it somewhere safe." Wait.
4. "Choose a username. It is the name others will see, so pick something you are happy to share. If it is taken, the page will suggest another." Wait.
5. "If it asks about email updates or your country or region, choose what you like." Wait.
6. "Complete the little verification puzzle it shows. It is there to check you are a person." Wait.
7. "GitHub emails you a code. Open your email, find the code and type it into the page." Wait.
   - If the code does not arrive: wait a minute, then check your spam or junk folder, check the email address was typed correctly, and use the page's **Resend** button. Still nothing: try a different email address.
8. "If it asks extra questions about your work or interests, you can skip them. If it asks you to choose a plan, choose the **Free** option." Wait.
9. "You should now see your GitHub home page. Is that what you see?"

Close with a warm "Well done, you now have a free account."
