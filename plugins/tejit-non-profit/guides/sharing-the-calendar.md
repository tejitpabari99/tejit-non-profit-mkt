# Sharing and using the events calendar

The tool puts events in their own calendar, named when you set it up (suggested: Partner Fundraising Events).

**Share it**
1. Open Google Calendar in a browser.
2. On the left, hover over the calendar's name, click the three dots, then Settings and sharing.
3. Under "Share with specific people", add your Board and leadership by email. Choose "See all event details" (or "Make changes to events" for people who add notes).
4. Click Send.

**Find events**
- Search by partner name at the top of Google Calendar: every title starts with the partner's name in brackets, and ends with the kind of event in parentheses, for example `[Partner Name] Annual Gala (Gala)`.
- Open an event to see the original link and when it was last checked.

**Add your own notes**
Open an event and scroll to the line `----- STAFF NOTES (never changed automatically) -----`. Type below that line. Everything below it is kept when the tool updates the event. Notes typed above the line can be overwritten.

**Good to know**
- The tool changes times or places when partners change them, and asks you when it is unsure. It never deletes events.
- If an event is missing, the partner may not have announced it yet.
