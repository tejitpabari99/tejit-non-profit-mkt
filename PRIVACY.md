# Privacy

[Terms and Conditions](https://github.com/tejitpabari99/tejit-np-plugin/blob/main/TERMS.md)

Tejit's Non Profit Tools counts how it is used, anonymously.

## What is collected
- Tool and version
- Event type
- Test-or-real flag
- Organization name as typed (lowercased)
- Random code
- Counts (items/ok/failed)
- Failing step (plus a reason category from the Google script)
- Automation chosen (plugin) / whether a send stopped early (script)
- UTC time
- A run code
- Which AI or app sent it (Claude, Google Apps Script, GPT, Gemini, Grok, Perplexity, other: a category only)

## What is never collected
- IP address
- Country
- Raw user-agent text
- Names
- Emails
- Recipients
- Partner lists
- Events
- File, draft or sheet names or contents
