# Phase 1: about this skill and permissions

Follow in order. Do not skip a wait.

1. **About this skill.** Send `templates/skill-about.md` (what it does, why it exists, what it will not do, 5 minutes once). WAIT for "continue" (answer questions first).
2. **Check connections** needed by THIS skill (listed in this skill's frontmatter `connectors`): Drive, Sheets, Calendar, web search/page reading. If a tool is not loaded, search for it before deciding it is missing. Connections marked "(optional)", such as GitHub, never block: do not walk the person through connecting them unless they ask.
3. **If any required one is missing**, guide the person with `templates/permission-help.md`, one connection at a time. Never continue until all work; stay patient.
4. **If all work**, send `templates/access-confirmation.md`. WAIT for a yes.
5. **Optional GitHub step (once per person).** Follow `../../start/references/github-step.md`. It is labelled "(optional)", is skipped if already done, and never blocks.
6. Continue to `prompts/02-onboarding-setup.md`.
