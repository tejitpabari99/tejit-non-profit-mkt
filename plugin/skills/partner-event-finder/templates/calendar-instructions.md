# Template: calendar creation (send as a chat message FIRST, then ask the name)

Message (in chat, not in a question widget):

> Google Calendar doesn't let me create a calendar for you, so here's how, it takes about a minute:
>
> 1. Open **Google Calendar** in your web browser (calendar.google.com).
> 2. On the left, find **"Other calendars"** and click the **+** next to it.
> 3. Click **"Create new calendar"**.
> 4. Type a name and click **"Create calendar"**.
>
> **Suggestion for the name: `Partner Fundraising Events`**

Then ask (short follow-up): "What name did you give the calendar? (Suggested: Partner Fundraising Events)". After they answer, list their calendars, find it by name, confirm "Is this the one: <name>?", and save its id.
